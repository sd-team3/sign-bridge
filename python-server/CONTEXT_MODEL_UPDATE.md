# 동작 관계·시간 흐름을 학습하는 수어 모델

모델: `curriculum70_context_v5_14signers`. 서비스는 기본 70단어·7챕터를 유지하며 내부적으로 100단어를 분류한다.

## 변경 내용

손 모양, 손과 몸의 위치 관계, 두 손 사이 거리, 시간에 따른 변화량을 별도 경로에서 인코딩한다. 시간 합성곱과 self-attention으로 동작의 전후 관계를 학습하고, 전체 주의집중 풀링과 시작·중간·끝 구간을 결합한다. 정규화한 표현과 학습한 클래스 중심으로 단어를 분류한다.

서로 다른 두 사람이 같은 단어를 수행한 자료와 각 자료의 두 증강본을 한 배치에 넣어 supervised contrastive loss를 적용했다. 같은 단어의 사람·촬영 차이는 줄이고 다른 단어는 구별하도록 학습한다. 증강은 단조로운 시간 변형, 작은 촬영 기울기·위치·크기 변화, 기존 책상 가림·추적 누락과 손 없는 준비·마무리 구간이다. 동작 순서를 뒤집거나 정상 정지 수어를 가짜 오답으로 만들지 않는다.

새 시간 모델과 기존 v4 모델을 결합한다. 결합 비율 0.5와 최종 온도 0.75는 REAL12 검증 자료만으로 선택했다. 기존 모델은 지원 70단어 내부의 분포에 기여하고, 보조 30단어에 배정한 확률 질량은 유지한다.

## 자료와 평가 절차

- 보관 원본: 14명 × 100단어 × 5방향 = 7,000개 영상.
- 모델 입력: F 정면 영상의 hands_body_v1 좌표. 영상·얼굴 표정·입 모양을 새로 학습한 모델은 아니다.
- 학습: REAL01~11, 1,100개. 검증: REAL12, 100개. 평가: REAL13~14, 200개.
- 평가 200개 중 서비스 단어는 140개, 과정 밖 보조 30단어는 60개다.
- 좌표 전처리와 쉬는 손 억제 seated_active_v2는 유지한다.
- 84회차에 조기 종료했고 검증 손실로 59회차를 선택했다. 모델·결합·온도를 고른 뒤 평가했다.
- REAL13~14는 이전 프로젝트 모델에서도 평가했던 인물이다. 이번 학습과 선택에서는 제외했지만 독립적인 새 사용자 시험이라고 해석하지 않는다.
- 배포 기준은 최종 평가 전에 deployment_gate.json에 기록했다. 평가 결과를 보고 재학습하거나 파라미터를 바꾸지 않았다.

## 같은 70단어·140개 영상 비교

| 조건 | 기존 v4 | 새 v5 |
|---|---:|---:|
| 원본 | 95.71% (134/140) | 97.86% (137/140) |
| 합성 책상 가림 0.75 | 92.14% (129/140) | 95.00% (133/140) |
| 합성 책상 가림 1.1 | 95.71% (134/140) | 98.57% (138/140) |
| 합성 책상 가림 1.5 | 96.43% (135/140) | 98.57% (138/140) |
| 합성 속도·위치·추적 변형 | 94.29% (132/140) | 97.14% (136/140) |

원본의 수락 결과: 기존 135개 중 정답 131개·오인식 4개, 새 모델 135개 중 정답 134개·오인식 1개다. 기존 모델에도 같은 margin 기준을 적용한 오수락 수는 4개다. 이 수락 결과는 모델과 서비스 판정 규칙을 함께 평가한 값이다.

100단어 전체 원본 분류는 98.00%다. 보조 30단어의 원본 60개는 모두 현재 과정 밖으로 구별했다. 보조 30단어도 이름을 알고 학습한 클래스이므로, 임의의 낯선 수어·무의미한 움직임을 모두 거절한다는 증거는 아니다.

합성 변형 결과는 실제 웹캠 성능을 뜻하지 않는다. 실제 사용자 오류·허용 변형과 문장 수어는 별도 수집·평가가 필요하다.

## 코칭의 판단 기준

유효한 촬영에서 목표 단어로 확신한 경우, 좌표 DTW 점수가 낮다는 이유만으로 틀렸다고 하거나 손을 특정 방향으로 옮기라고 강제하지 않는다. 주 안내는 학습한 단어 인식 결과다. 손 높이·거리·각도 차이는 '모범 영상과 비교해 보기 · 참고' 안에서 선택적으로 확인한다. 비교 점수는 정답 판정 점수가 아니다.

모델의 최상위 확률 0.7 이상, 2위와의 차이 0.15 이상을 수락 기준으로 사용한다. 불확실하면 재촬영을 안내한다. 보조 30단어로 인식하면 outside_curriculum으로 재시도하며 지원 70단어 중 하나로 강제하지 않는다. 실제 손 검출 부족은 기존 촬영 품질 검사를 유지한다.

학습한 단어로 분류됐다는 사실이 수어 문법·모든 손가락 표현의 정확성을 보장하지는 않는다. 정답과 오답을 판정하는 별도의 전문가 코칭 모델을 학습한 것은 아니다. 새 정책에서는 좌표 차이와 분류 결과를 구분하며, LLM으로 좌표 교정을 덧붙이지 않는다.

## 연동

- Python은 기존 API·원시 좌표 입력 형식을 유지하고 새 모델 factory로 v4/v5를 모두 읽는다.
- health의 classes=70, model_output_classes=100, architecture=context_fusion_v1, feedback_policy=semantic_v1이다.
- recognition.accepted가 false이면 시험은 확인 필요로 처리한다. 시험의 수동 녹화는 유지한다.
- 학습의 자동 녹화·초록 테두리도 유지한다. 결과 화면만 새 코칭 정책을 따른다.
- 70단어 시범 210개는 유지하며 모두 학습 인물 REAL01~03이다.
- 모델이 바뀐 기존 시험은 새 시험으로 시작한다.
- 데스크톱과 동영상 CLI도 모델 factory를 지원한다. 데스크톱은 activated.json이 있는 새 모델을 우선한다.

학습·선택·평가 기록: D:/sign-lang/artifacts/curriculum70_context14.
백업 위치와 체크포인트 해시: 해당 폴더 activated.json.

## 배포 검증

Python 검사 45개, 모델·의미 피드백 단위 검사 6개, Spring·DB 검사 46개와 화면·자동 녹화 검사를 통과했다. Docker의 실제 Spring→Python→MySQL 영상 평가, 결과 복원, 가상 웹캠의 손 감지→자동 녹화→새 모델 인식, 과정 밖 단어 영상의 outside_curriculum 응답을 확인했다. 테스트 계정 1개와 시험 기록 3개는 삭제했다. 실제 사용자 웹캠 환경의 별도 성능 평가는 아직 수행하지 않았다.
