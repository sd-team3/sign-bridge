# 기본 70단어 모델·코칭·Spring 반영 결과

적용일: 2026-10-28. 기존 100단어 선정 목록에서 `기본70` 7개 단원만 사용한다.
학습 REAL01~05 350개, 검증 REAL06 70개, 평가 REAL07~08 140개다.
이미 추출한 hands_body_v1 특징을 재사용하며 학습·검증·평가 인물은 분리했다.
REAL07과 REAL08은 이전 프로젝트 평가에 사용된 인물이라 독립 신규 사용자 성능으로 해석하지 않는다.

| 같은 기본70 평가 영상 | 기존 100클래스 모델의 출력을 70개로 제한 | 새 70클래스 모델 |
|---|---:|---:|
| 원본 140개 | 87.1% (122/140) | 91.4% (128/140) |
| 합성 가림 0.75 | 80.0% | 85.7% |
| 합성 가림 1.10 | 82.9% | 89.3% |
| 합성 가림 1.50 | 86.4% | 92.1% |

새 모델의 인물별 결과는 REAL07 66/70, REAL08 62/70이다.
검증 손실로 98회차를 선택했다. 새 모델은 처음부터 학습했고 label smoothing 0.04,
검증 손실에 따른 학습률 감소, 좌우 반전 예측 결합을 적용했다.
검증셋에서 temperature 0.65를 선택했다. 검증 NLL은 0.2179에서 0.1498로 줄었다.
테스트 정확도를 보고 체크포인트·온도·임계값을 고르지 않았다.
합성 가림 결과는 실제 앉은 웹캠 성능을 뜻하지 않는다.

코칭 변경:

- 시범 1명만 쓰던 방식을 학습 인물 3명의 시범으로 늘렸다. 시험 인물 시범은 사용하지 않는다.
- REAL02/03 비교 좌표는 같은 WORD 원본의 기존 특징에서 복원했다. 손 위치·각도 복원은 원시 좌표 계산과 수치 비교 검사했다.
- 비교 가능한 시범과 좌우 반전 상태를 선택하고, 실제 사용한 시범을 화면에서 볼 수 있게 했다.
- 손의 안쪽/바깥쪽 차이도 관측되면 직접 안내한다. 불확실한 교정 방향은 만들지 않는다.
- 필수 피드백과 행동 목록이 스프링 화면에서 누락되지 않게 했다.
- 분류 확률과 동작 비교 점수는 다른 지표로 유지한다.

이 브랜치의 반영 범위:

- Python API, 기본70 모델·목록·챕터·비교 시범, 코칭 로직과 관련 검사.
- Spring 소스와 화면, 빌드 설정, 인증 설정, 기존 지문자 기능은 변경하지 않는다.
- `SIGN_FEEDBACK_SIMILARITY_THRESHOLD` 기본값은 70이다. 낮은 점수·오인식·측정 부족 시 안내를 반환한다.
- `feedback.reference.video_url`의 시범 variant 경로는 Python에만 추가한다. Spring 중계와 화면 표시는 별도 반영 대상이다.
- 모델 ID는 `curriculum70_seated_v3`, health에서 70클래스·7챕터·210개 시범을 확인할 수 있다.
- Python 프로세스를 재시작하거나 Docker 이미지를 다시 빌드해 적용한다. 기존 SIGN_MODEL_PATH가 다른 모델을 가리키면 갱신한다.
- 검사는 `python -m unittest discover -s tests -v`, 실제 영상 검사는 `python tests/smoke_sign_word_video.py`로 실행한다.

모델은 기존 검증 결과를 이식한 것이며 이번 브랜치에서 다시 학습하지 않았다.
