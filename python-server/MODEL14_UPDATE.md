# 14명 자료를 반영한 기본70 모델

적용일: 2026-11-03. 모델 ID: `curriculum70_seated_v4_14signers`.

## 자료와 분리

- REAL01~14 각각 선정 100단어 × 5방향, 총 7,000개 영상이 `D:/sign-lang/data/curriculum_videos`에 있다.
- 100단어의 정면 영상 1,400개에서 hands_body_v1 특징을 저장했다. 확장용 30단어도 원본과 특징을 보관한다.
- 서비스 모델은 기본70·7챕터를 유지한다. 학습 REAL01~11 770개, 검증 REAL12 70개, 최종 평가 REAL13~14 140개다.
- 13~14번은 학습, 체크포인트 선택, 온도 보정과 코칭 시범에 사용하지 않았다. 기존 모델도 같은 140개 영상에서 평가했다.
- 다른 방향의 영상은 원본으로 보관하고 이번 모델 학습은 웹캠의 정면 환경에 맞춰 F 영상만 사용했다.

## 학습

기존 가중치를 이어 학습하지 않고 seed 42로 처음부터 학습했다. BiLSTM hidden 96·1층, 입력 154, 시퀀스 64를 유지했다. 쉬는 손 억제 `seated_active_v2`, 책상 가림·시간 변화·추적 누락 증강과 좌우 반전을 사용한다.

REAL12의 원본/합성 가림 교차엔트로피로 70회차를 선택했다. 최종 평가는 선택 이후 수행했으며 평가 점수로 모델이나 온도를 다시 고르지 않았다. 온도 0.65도 REAL12만 사용해 정했다. 가중 검증 NLL은 0.1505에서 0.0985로 바뀌었다.

## 적용

- Python: `sign_api/assets/best.pt`, `manifest.json`, `evaluation.json` 갱신.
- Spring: 기존 학습·시험의 영상 평가 호출이 새 모델을 사용한다. `GET /api/sign-learning/health`에서 모델 ID, 14명 자료와 학습·검증·평가 인물을 확인할 수 있다.
- 기존 70단어 카탈로그와 코칭 시범 210개는 유지한다. 코칭 시범은 학습 인물 REAL01~03뿐이다.
- 동작 비교 피드백 기준은 70, 시험 인식 확률 기준은 0.7로 유지한다. 온도 보정값과 동작 비교 점수는 별개다.
- 학습 자동 녹화·초록 테두리와 시험의 수동 녹화 방식은 유지한다. 지문자 모델은 변경하지 않는다.
- 시험 중 모델이 변경된 기존 응시는 새 시험으로 시작해야 한다. 시험 서비스가 서로 다른 모델의 결과를 같은 시험에 섞지 않도록 검사한다.
- 데스크톱 `practice50.py`도 완료된 14명 모델을 우선 사용한다.
